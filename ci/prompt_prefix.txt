Before optimizing, run this shell prelude exactly:

  export HYPERLOOM_SOURCE_REPO="${HYPERLOOM_SOURCE_REPO:-https://github.com/AMD-AGI/Hyperloom.git}"
  export HYPERLOOM_SOURCE_REF="${HYPERLOOM_SOURCE_REF:-main}"
  export HYPERLOOM_SOURCE_DIR="${HYPERLOOM_SOURCE_DIR:-/tmp/Hyperloom-main}"
  mkdir -p "$(dirname "$HYPERLOOM_SOURCE_DIR")"
  rm -rf "$HYPERLOOM_SOURCE_DIR"
  if ! git clone --depth 1 --branch main "$HYPERLOOM_SOURCE_REPO" "$HYPERLOOM_SOURCE_DIR"; then
    echo "[FATAL] git clone of Hyperloom failed — refusing to fall back to /wekafs/HyperloomV2" >&2
    exit 1
  fi
  cd "$HYPERLOOM_SOURCE_DIR"
  if [ "$HYPERLOOM_SOURCE_REF" != "main" ]; then
    if ! git fetch --depth 1 origin "$HYPERLOOM_SOURCE_REF"; then
      echo "[FATAL] git fetch of pinned ref $HYPERLOOM_SOURCE_REF failed" >&2
      exit 1
    fi
    git checkout --detach FETCH_HEAD
  fi

SAFETY:
- NEVER `find /` or `find /wekafs` without `-maxdepth 4`. Prefer which/ls/$PATH lookups.
- NEVER run `kill -9 $(ps aux | grep ...)` — this kills the sandbox executor itself.
- Per-bash timeouts must be <= 120s; use short polling loops rather than one long blocking call.
- Modification of USER_DATA_PATH environment variable is not allowed.
- After the prelude, always `cd "$HYPERLOOM_SOURCE_DIR"` and use that checkout as the only Hyperloom source for install, skill docs, CLI execution, and new-session decisions; ignore historical sessions under USER_DATA_PATH before this task's first launch.
