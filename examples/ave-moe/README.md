# Ave MoE review reproduction

Run a synthetic MoE workload through Hyperloom: baseline → Ave optimization → apply patch → remeasure → KEEP/REVERT.

## Before running

1. **Use MI350/MI355 GPUs (gfx950) in a ROCm development container:** one GPU for LocalMoE, or eight GPUs on the same node for MegaMoE.
2. **Configure Claude authentication** in your environment or the repository-root `.env`: `CLAUDE_CODE_OAUTH_TOKEN=your-token` for a subscription (get it with `claude setup-token`), or `ANTHROPIC_API_KEY=your-api-key` for API access. See [authentication](../../docs/reference/authentication.md) for gateways.

## Run

From the Hyperloom repository root, select a suite:

```bash
bash examples/ave-moe/run.sh localmoe
```

```bash
bash examples/ave-moe/run.sh megamoe
```

| Suite | Workload | Recipe | GPUs |
|---|---|---|---|
| LocalMoE (default) | GPT-OSS / DeepSeek V3 / V4, 8/128/1024 tokens | [18 steps](localmoe/recipe.json) | 1 |
| MegaMoE | Kimi K3 EP8, 8/32/128 tokens per rank | [7 steps](megamoe/recipe.json) | 8 |

Both recipes retain the optimization order, required changes, file scopes, invariants and exclusions from `avelang-moe-suite`. MegaMoE starts from its own pinned initial source; running LocalMoE first is unnecessary. Its driver launches eight ranks, checks two consecutive calls against the collective reference (worst-rank SNR ≥ 30 dB), and reports the slowest rank's graph timings.

For a short trial, select only the first prompt:

```bash
bash examples/ave-moe/run.sh megamoe --max-steps 1
```

Defaults: **Sonnet with medium effort, Ray disabled, up to 60 minutes per optimization step**. The total session budget is one hour per selected prompt plus one hour for baseline and validation; `--max-steps 2` therefore allows three hours in total. `CLAUDE_CODE_EFFORT_LEVEL` can override the effort level. Omitting `--max-steps` selects the full recipe. LocalMoE uses GPU 0 and MegaMoE uses GPUs 0–7 unless `ROCR_VISIBLE_DEVICES` is already set. To choose another GPU or workspace:

```bash
ROCR_VISIBLE_DEVICES=1 bash examples/ave-moe/run.sh localmoe /workspace/moe-review
```

## Setup and output

The script reuses installed ROCm Torch and AITER. Missing Torch is installed from the official wheel index matching `/opt/rocm/.info/version` (version range 2.9.1–2.12.0); setup stops if there is no compatible wheel. Missing AITER is built from pinned public source. Existing CPU/CUDA Torch is rejected.

It then installs Hyperloom dependencies, downloads and builds pinned public [LLVM](https://github.com/ROCm/llvm-project) and [AveLang](https://github.com/xindubawukong/avelang) sources, initializes Hyperloom's runtime without Ray, and launches `hyperloom optimize`. No existing AveLang checkout or LLVM installation is needed. The first compiler build can take hours; reruns reuse its build directory.

The default workspace is `~/ave-moe-optimization`:

- `llvm-project/`: shared compiler source and build.
- `localmoe/avelang/` and `megamoe/avelang/`: independent pinned starting sources.
- `<suite>/prompts.json`: generated by `prepare.py` from [shared knowledge](../../src/ave/knowledge/), the selected recipe and fixed driver, without LLM calls.
- `sessions/<suite>/.../`: Hyperloom runs. Each session contains `ave/run-*/result.json`, remeasurement under `runs/integrate/`, and the integration verdict in `state.json`.

Keep the workspace: the installed compiler uses its build artifacts. Setup reuses clean checkouts at the pinned revisions and refuses tracked edits. To repeat a campaign after KEEP has changed its serving sources, choose a new workspace. Rerunning `run.sh` starts a new Hyperloom session; it does not resume a previous session.
