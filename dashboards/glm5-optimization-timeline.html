MAR 26 PM · PHASE 3

v3 — The Three-Way Combo Breakthrough

1,981 tok/s
+43.6% from baseline · TPOT 59ms

Found the winning combination: aiter NSA decode + mixed-chunk scheduling + allreduce fusion. Each gave 0–3% alone. Together: +41.2% jump. The three optimizations compound multiplicatively.

--nsa-decode-backend aiter AMD's hand-tuned Composable Kernel (CK) implementation replaces Triton auto-generated code, exploiting MI355X's MFMA units and LDS more efficiently
--enable-mixed-chunk Mixes decode tokens into prefill batches, eliminating GPU idle time between phases
--enable-aiter-allreduce-fusion Fuses allreduce → RMSNorm → quantization into a single kernel, hiding communication latency behind compute
synergy Communication overlap + reduced idle time + faster attention compound multiplicatively, not additively

MAR 29 · PHASE 6

v7 — MoE Router GEMM Tuning Breakthrough

2,070 tok/s
+50.1% from baseline · TPOT 58ms · +21.4% from v7 baseline

Discovered a missing GEMM tuning config for the MoE router's (N=256, K=6144) shape. Adding ksplit=24 maximized CU occupancy across all 256 Compute Units. Single largest optimization: +21.4%.

ksplit=24 K dimension (6144) split into 24 parallel chunks, each processed by a CU group. Default left most CUs idle during router GEMM.
why it matters Router GEMM runs once per layer × 78 layers. Slow router serializes the entire MoE dispatch pipeline for 256 experts.
A8W8 Triton Tried rerouting MLA GEMMs to Triton — resulted in -5.1% regression. CK kernels are faster for these shapes.

MAR 30 · PHASE 8

v8+ — Final Result & Gap Analysis

2,039 tok/s
+47.8% from baseline · TPOT 60ms · Verified reproducible

Aggressive optimization attempts (dense GEMM tuning, fMoE kernel mods, RCCL experiments) yielded no further gains. Profiling showed 44.9% of decode time is allreduce communication — a hardware limit. Clean-state replication confirmed 2,039 tok/s is reproducible.

profiling AllReduce: 44.9% of time · GPU idle: 49% · 124 calls/step × ~200μs each — decode is communication-bound
vs NVIDIA B200 509.8 tok/s/GPU (MI355X) vs 660 tok/s/GPU (B200) = 23% gap. NVLink 5 has ~5μs latency vs Infinity Fabric ~20μs — hardware limit.
unreachable FP8 KV cache broken (tensor reshape bug in aiter NSA path), no compute-communication overlap (NVIDIA SBO), no JIT GEMM (DeepGEMM)
