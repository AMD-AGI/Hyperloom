# About Hyperloom

Hyperloom is developed by AMD AGI as part of the ROCm platform for autonomous
LLM inference optimization on AMD GPUs.

This page covers Hyperloom's background, licensing, policies, and external resources.

## Blog

- [Hyperloom UI (PrimusClaw)](https://core42.primus-safe.amd.com/hyperloom/) —
  the hosted online mode.
- [ROCm Blogs — LLM inference optimization](https://rocm.blogs.amd.com/blog/tag/llm.html)
  — the official AMD blog stream covering ROCm inference optimization.

## License

Hyperloom is released under the **Apache License 2.0**. The full license text
is in [`LICENSE`](https://github.com/AMD-AGI/Hyperloom/blob/main/LICENSE); the
same license is asserted in `pyproject.toml` for PyPI and sdist consumers.

You can use Hyperloom commercially, modify it, and distribute it under the terms
of Apache-2.0. Patent grants and NOTICE handling follow the standard Apache-2.0
rules.
