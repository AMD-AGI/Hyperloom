关键观察
  • +14.95% 增益主体来自 KERNEL 的 forge GEMM 调优 (+11%) 与 EXPLORE 的 FP8 KV cache (+8% 单独);两者是仅有的两个大杠杆,其余均为 <1% 的 config 微调。
  • 与 32B(dense)不同:30B-A3B 是 MoE,因此 MoE GEMM 调优成为最大收益来源(32B 的 KERNEL 阶段为 0)。
  • FRAMEWORK_PR 净收益为 0:本机 vLLM/aiter 为 wheel 安装、无 git checkout,PR 源码补丁无法 git apply,只能降级 config-lever 而被 EXPLORE 覆盖 → 全部 REVERT。属环境约束,非 agent 缺陷。
  • cyclic 多宏周期有效:跑满 6 个 macro-cycle,framework-agent 每轮从 36–40 个 PR 候选中 LLM 排序选取并完整评测,逐轮叠加 config 微调把全栈推到 +14.95%。运行因 48h wall-clock 预算收尾(非收敛退出)。
  • benchmark 噪声 ~±10% 是中途累计值波动(11.6%→7%→14.95%)的主因;每次 KEEP 后的全栈 rebench 给出诚实的累计值。
