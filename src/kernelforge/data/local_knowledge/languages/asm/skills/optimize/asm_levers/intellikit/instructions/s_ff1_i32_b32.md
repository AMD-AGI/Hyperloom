# s_ff1_i32_b32

Find first bit set (from LSB): returns the bit position of the lowest set bit, or -1 if input is 0. Equivalent to `ctz` (count trailing zeros).

## Quick Facts

| Property | Value |
|----------|-------|
| Encoding | SOP1 |
| Throughput | ~1 shader cycle (standard SALU issue rate) |
| Category | Scalar ALU |

## Hazards

None specific to this instruction.

## Known Bugs / Gotchas

### Used for integer log2 computation

`s_ff1_i32_b32` can compute `floor(log2(x))` for power-of-two values. For non-power-of-two values, it finds the position of the least significant set bit, which is useful for computing alignment or decomposing values into shift amounts.

```asm
; For x = 64: s_ff1_i32_b32 returns 6 (bit 6 is set)
; For x = 128: returns 7
; For x = 0: returns -1 (0xFFFFFFFF)
s_ff1_i32_b32 s_log2, s_value
```

### Not the same as s_flbit_i32_b32

`s_ff1_i32_b32` finds the LOWEST set bit (from LSB). `s_flbit_i32_b32` finds the HIGHEST set bit (from MSB). For computing `floor(log2(x))`, use `s_flbit_i32_b32` (find first bit from MSB) or `31 - s_ff1_i32_b32(reverse(x))`.

## Common Usage Patterns

### Power-of-two decomposition
```asm
; Decompose a stride into shift amount:
s_ff1_i32_b32 s_shift, s_stride   ; stride=64 -> shift=6
; Use shift for address computation:
v_lshlrev_b32 v_addr, s_shift, v_idx
```

### Loop iteration computation
```asm
; Compute number of K-tiles from K dimension (power-of-two K):
s_ff1_i32_b32 s_log2_k, s_k_dim
s_sub_u32 s_n_tiles, s_log2_k, s_log2_tile_k
```
