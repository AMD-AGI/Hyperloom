# v_mfma_f32_32x32x16_f16

FP16 matrix fused multiply-add, 32x32 output tile, K=16. Larger tile FP16 variant, identical pipeline behavior to the BF16 32x32x16 variant.

---

## Quick Reference

| Field | Value |
|-------|-------|
| Opcode | `v_mfma_f32_32x32x16_f16` |
| Tile Shape | 32 rows x 32 cols, K=16 |
| Input Type | FP16 (packed pairs in VGPRs) |
| Output Type | FP32 (accumulated in AGPRs) |
| Latency | ~32 cycles |
| Issue Rate | ~32 cycles |
| FLOPs | 32 * 32 * 16 * 2 = 32,768 |
| Measured CPI | 31.2 shader cycles (isa-bench, raw FCLK CPI = 1.344) |

---

## Output Layout (Column-Major)

Identical to v_mfma_f32_32x32x16_bf16:

```
Half h = l / 32         (0 or 1)
Lane l: N = l % 32      (column index, 0..31)

VGPR k (0..15): M = h*4 + (k%4) + (k/4)*8
```

16 AGPRs per instruction output.

---

## Operand Requirements

| Operand | Register | Count | Constraint |
|---------|----------|-------|------------|
| Src0 (A) | VGPRs | 4 | Must be VGPRs, NOT AGPRs |
| Src1 (B) | VGPRs | 4 | Must be VGPRs, NOT AGPRs |
| Src2/Dst (C/D) | AGPRs | 16 | Accumulator input/output |

---

## Co-Execution Window

| Cycle Range | Activity |
|-------------|----------|
| 0-7 | Reads A, B, D operands. No co-execution. |
| 8-31 | Free. Co-exec: TEX, LDS, ALU0, LD_SCALE. |
| 32+ | Can issue next MFMA. |

---

## NOP Requirements

Same as all MFMA instructions on gfx950:

| Transition | Required Wait |
|------------|---------------|
| `s_waitcnt` -> this MFMA | **0 NOPs** |
| VALU write -> this MFMA (same src VGPR) | **2 NOPs** (s_nop 1 x 2) |
| This MFMA -> another MFMA (diff AGPR dest) | **0 NOPs** |
| Last MFMA -> `v_accvgpr_read_b32` | **64 NOPs** (s_nop 15 x 4) |
| `v_accvgpr_write_b32` -> this MFMA (same AGPR) | **1 NOP** (s_nop 0) |

## Use Cases

- **FP16 attention**: Larger tile variant for FP16 attention kernels.
- **FP16 GEMM (large tiles)**: When FP16 inputs are available and larger tiles are needed for arithmetic intensity.
