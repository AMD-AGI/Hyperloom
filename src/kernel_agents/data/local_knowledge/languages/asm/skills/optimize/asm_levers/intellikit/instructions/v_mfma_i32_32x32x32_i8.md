# v_mfma_i32_32x32x32_i8

INT8 matrix fused multiply-add, 32x32 output tile, K=32. Larger tile INT8 variant.

---

## Quick Reference

| Field | Value |
|-------|-------|
| Opcode | `v_mfma_i32_32x32x32_i8` |
| Tile Shape | 32 rows x 32 cols, K=32 |
| Input Type | INT8 (packed in VGPRs) |
| Output Type | INT32 (accumulated in AGPRs) |
| Latency | Not measured |
| Issue Rate | Not measured |
| FLOPs | 32 * 32 * 32 * 2 = 65,536 integer OPs |
| Measured CPI | ~8.2 shader cycles (isa-bench, raw FCLK CPI = 1.406) |

---

## Output Layout

Not measured. Expected to follow the same 32x32 column-major layout as v_mfma_f32_32x32x16_bf16:

```
Half h = l / 32         (0 or 1)
Lane l: N = l % 32
VGPR k (0..15): M = h*4 + (k%4) + (k/4)*8
```

16 AGPRs per instruction output.
