# Contributing

This directory is a vendored copy of Arbor ([`VENDOR.md`](VENDOR.md)). It is not edited here: a change is made in
Arbor's own repository, and the copy is taken again, whole, from a new tag.

- **How a host runs Arbor:** [`docs/hosts.md`](docs/hosts.md) and [`docs/component-mode.md`](docs/component-mode.md).
- **How Arbor works, and its keys and files:** [`docs/how-it-works.md`](docs/how-it-works.md) and
  [`docs/reference.md`](docs/reference.md).
- **A problem with Arbor as this repository runs it:** report it to this repository's maintainers, who take it to
  Arbor's.
